# AI 截图助手

> 按一个键 → 截图 → 问 AI → 结果弹出来。
> 打包成单个 exe，整个扔进移动硬盘，换台电脑双击即用。

---

## 解决的到底是什么

遇到看不懂的报错、陌生界面、一张看不出所以然的表格，
原来的动作是：截图 → 保存 → 打开网页 → 上传 → 粘贴问题 → 等。

六步，每一步都在打断当前的事。

现在是一步：按快捷键。

---

## 模块拆解

| 文件 | 职责 |
|---|---|
| `main.py` | 主程序入口，装配所有模块 |
| `screenshot.py` | 截图：全屏 / 鼠标框选，DPI 修正，压缩编码 |
| `ai_client.py` | AI 客户端：OpenAI 兼容接口 + 本地 Ollama |
| `hotkey_manager.py` | 全局热键：keyboard 优先，pynput 兜底 |
| `ui_handler.py` | 主窗口 / 托盘 / 结果窗 / 加载提示 / 框选遮罩 |
| `web_server.py` | 局域网手机同步页（标准库实现，零额外依赖） |
| `make_icon.py` | 生成 icon.ico |

## 几个值得说的细节

### DPI 修正

高分辨率屏上截图容易只截到左上角一块。
这不是 bug，是 Windows 的 DPI 缩放导致的——程序声明的 DPI 感知级别
和系统实际给的不一致。必须显式处理，否则 200% 缩放下截出来的图是错的。

### 热键用两个库兜底

`keyboard` 优先，失败就退回 `pynput`。

原因是某些环境下 `keyboard` 需要管理员权限才能注册全局钩子，
装上才发现用不了。与其让用户自己去排查，不如代码里直接降级。

### 手机同步用标准库写

`web_server.py` 不引任何第三方依赖，用 Python 标准库起一个局域网服务。

电脑截图 + AI 解答实时同步，手机连同一 WiFi 打开网址就能看。
适合人不在电脑前的时候。

> 安全性上做了处理：默认带一个随机访问口令，且默认只监听局域网。
> 这个功能会把屏幕内容暴露给同网的人，所以是**可选的**，不开就是纯本地。

### 模型可换

`config.ini` 里换 `base_url` 和 `model` 就能切：
DeepSeek、OpenAI、通义千问都走 OpenAI 兼容格式。

也可以设成本机 Ollama，**完全离线、不需要任何 API Key**。

## 怎么用

```bash
pip install -r requirements.txt
cp config.example.ini config.ini   # 填入你自己的 API Key
python main.py
```

Windows 上一键打包：

```bat
build.bat
```

---

## 打包踩过的坑

- PyInstaller 打 `onefile` 时，venv 下的 tkinter 可能找不到 Tcl → 需要显式指定路径
- 托盘图标必须跑在**独立线程**，否则主线程一忙界面就假死
- 后台线程不能直接更新 Tk 界面，要走线程安全的方式投递

这几条都写进代码注释了，下次打包不用再查一遍。
